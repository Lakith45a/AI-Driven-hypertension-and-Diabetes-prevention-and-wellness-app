# AI-Driven Hypertension and Diabetes Prevention and Wellness App

## Individual Component: AI Health Coach for Stress & Hypertension (IT22623690)

This module implements a domain-specific AI health coach focused on:

- Stress detection using the PSS-10 questionnaire
- Personalized stress reduction recommendations
- Sri Lanka–specific wellness guidance
- Hypertension-related Q&A support (non-diagnostic)

> ⚠️ This system is for awareness and preventive guidance only. It does not provide medical diagnosis.
