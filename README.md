# AI-Driven-hypertension and Diabetes-prevention-and-wellness-app
## Individual Component: Early Hypertension Risk Prediction & Personalized Recommendation (IT22178886)


## 📘 Project Overview
This project focuses on developing an **AI-powered, real-time hypertension prevention and wellness system** tailored specifically for **Sri Lankans**.  
The system predicts **early risk of hypertension** by analyzing **lifestyle and stress-related data**, then delivers **personalized lifestyle recommendations** covering diet, physical activity, and stress management.

Unlike generic Western clinical models, this project emphasizes **cultural adaptation**, using locally relevant factors such as high salt intake, sedentary lifestyles, and dietary habits common in Sri Lanka.

---

## 🧠 Component Description — Early Hypertension Risk Prediction & Recommendation
The **Early Hypertension Risk Prediction & Recommendation** module is responsible for:
- Predicting early risk of hypertension using AI/ML models trained on behavioral, lifestyle, and demographic data.  
- Generating **personalized, explainable recommendations** to help users reduce risk before clinical onset.  
- Supporting **real-time adaptation** using continuous data from self-reported lifestyle surveys.

---

## 🎯 Objectives
1. Develop a **lightweight ML model** for real-time hypertension risk prediction.  
2. Integrate lifestyle (salt intake, sleep, stress, physical activity).  
3. Provide **explainable AI** feedback showing key factors influencing each user’s risk.  
4. Deliver **personalized wellness recommendations** through a mobile/web app interface.  
5. Validate model performance using local Sri Lankan data to ensure cultural relevance.
